# Deploy ArtPeriod

## Local
1. Install dependencies: `npm install`
2. Run dev: `npm run dev`
3. Build: `npm run build`

## GitHub
1. Create a repo under `dialsandrew0`.
2. Push this project to `main`.

## Vercel
1. Import the GitHub repo.
2. Accept default Next.js settings.
3. Add any environment variables if you later connect APIs.
4. Deploy.

## Notes
- This scaffold currently uses local state and static content.
- Replace placeholders with real data when ready.
